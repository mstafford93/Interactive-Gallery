Interactive Gallery
A gallery where you can type the name of an image in this case "example1", "example2", "example3" into the input field.
It will return the corresponding image, with a remove button function to remove the image in the same div.
This hopefully showcases practical application of JavaScript events, DOM manipulation. 
This is my progress so far i expect to improve these skills in the future.

Dependencies:
  - HTML 5
  - CSS
  - JavaScript

Usage
  - Run in a source-code text editor (e.g. Visual Studio Code) to view code
  - Run in web browser to see website

Configuration 
  - No config needed
